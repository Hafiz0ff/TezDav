Политика конфиденциальности

1. Общие положения

Мы высоко ценим конфиденциальность ваших данных. Настоящая Политика конфиденциальности объясняет, как мобильное приложение TezDav обрабатывает, хранит и защищает вашу информацию.

2. Локальное хранение данных

Все ваши спортивные метрики, GPS-треки, файлы тренировок (GPX/FIT), показатели пульса и настройки профиля сохраняются исключительно локально на вашем устройстве во встроенной зашифрованной базе данных iOS (SwiftData/SQLite) и защищенном хранилище Keychain.

Приложение не имеет собственных внешних серверов баз данных и не передает ваши персональные данные третьим лицам.

3. Интеграция с Strava API

TezDav использует официальное API сервиса Strava исключительно для выполнения следующих задач по вашему запросу:

  • Авторизация пользователя и получение токенов доступа.
  • Считывание списка ваших спортивных активностей и их деталей.
  • Синхронизация истории ваших тренировок с локальной базой данных приложения.

Токены авторизации сохраняются в системном Keychain вашего устройства. Вы можете в любой момент отозвать авторизацию в настройках профиля приложения.

4. Датчики и разрешения iOS

Приложение может запрашивать доступ к следующим функциям вашего устройства:

  • HealthKit (Apple Здоровье): Используется исключительно для чтения пульсовых данных, показателей сна и HRV с целью расчета индекса готовности (Readiness Score) локально на устройстве.
  • Геолокация: Используется только для записи трека в реальном времени при симуляции тренировок или построении маршрутов на карте.
  • Push-уведомления: Служат для информирования о новых личных рекордах и подготовки еженедельных спортивных отчетов.

5. Изменения политики конфиденциальности

Мы можем обновлять данную политику конфиденциальности по мере добавления новых функций. Все обновления вступают в силу с момента публикации новой версии приложения в App Store.
