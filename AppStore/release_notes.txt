Добро пожаловать в TezDav 1.0!

Первая публичная версия приносит полный набор аналитических инструментов для спортсменов:
• Подробный анализ беговой динамики: частота шагов, время контакта с землей, вертикальные колебания и длина шага.
• Оценка спортивной формы с помощью накопленной тренировочной нагрузки (модели CTL/ATL/TSB).
• Персональный ИИ-тренер для адаптивных советов по тренировкам.
• Прогресс исследования территории с интерактивными тепловыми картами и гео-экстремумами.
• Премиальный визуальный шаринг тренировок (Workout Cards в 1080p для Stories и публикаций).
• Полная поддержка VoiceOver для незрячих пользователей, Dynamic Type и режима «Уменьшение движения».
• 100% конфиденциальность с локальной обработкой данных на вашем устройстве.
